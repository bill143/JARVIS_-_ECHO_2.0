    Skills

    A skill is a SKILL.md file (agentskills.io format): a name, a description and written instructions. JARVIS sees the name and description and reads the full instructions when a request needs them.

    Bulk add: copy skill folders (each with a SKILL.md), folders of skill folders, or .zip files into the skills folder. They load when this page opens, when JARVIS starts, or with Rescan.
