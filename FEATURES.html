JARVIS & ECHO 2.0 — Feature Catalog

Best viewed in landscape (it prints landscape automatically — File → Print → Save as PDF). Columns: Name · Function · Summary · Activate · File Location. Paths are relative to the repository root. Use the tabs to switch between what's installed and what's available but not installed.

⚡ Complete Setup — one file does everything

This runs a Computer Setup Search (scans your PC, read-only), then installs Python + all the libraries, asks for your API keys once, and launches Alloy.

⬇ Complete Setup (Windows) ⬇ Complete Setup (Mac)

How this works (please read): for your safety, a web link cannot run a program on your computer — so clicking the button downloads the setup file. Then double-click the downloaded complete-setup.bat to run it. If Windows shows a blue “Windows protected your PC” box, click More info → Run anyway (it's your own file). Easiest of all: just double-click complete-setup.bat inside the vision-agents folder.

Alloy — Voice + Vision Assistant primary app

Talk to it in your browser; it hears, sees (via Claude + Moondream), and talks back. Built on GetStream Vision Agents. Folder: vision-agents/

NameFunctionSummary of featureActivate (how to activate)File location
Real-time call Transport / connection Browser webcam + mic streamed over Stream's low-latency edge network; the agent joins the call. Run setup, then a demo page opens — allow camera + mic and start talking. vision-agents/agent.py getstream.Edge
Speech-to-text Hearing Deepgram transcribes your speech and handles turn-taking (knowing when you've finished). Automatic whenever you speak. vision-agents/agent.py deepgram.STT
The brain (Claude) Reasoning + persona Claude Opus 4.8 holds the conversation, the "Alloy" personality, and decides which tool to call. Automatic. Change the model via LLM_MODEL (e.g. claude-sonnet-4-6 for cheaper). vision-agents/agent.py anthropic.LLM
Text-to-speech Voice ElevenLabs turns Claude's replies into a natural spoken voice. Automatic. Change the voice via the ElevenLabs model_id. vision-agents/agent.py elevenlabs.TTS
Webcam capture Eyes (frame buffer) A tiny processor keeps the latest webcam frame so the vision tools can ask about it on demand. Automatic when your camera is on. Tune refresh via VISION_FPS. vision-agents/agent.py WebcamEyes
look Vision tool Claude calls Moondream's vision model on the current frame to describe what's on camera. Say "What do you see?" / "What am I holding?" vision-agents/agent.py look()
read_text Vision tool (OCR) Reads and transcribes any text you hold up to the camera — labels, signs, pages, screens. Say "Read this label / sign / page." vision-agents/agent.py read_text()
find_object Vision tool (detect) Checks whether a named object is currently visible using Moondream object detection. Say "Can you see my keys / mug / phone?" vision-agents/agent.py find_object()
get_weather Info tool Returns current weather for a city or location (built-in helper — no extra key). Say "What's the weather in Boston?" vision-agents/agent.py get_weather()
get_current_time Info tool Gives today's date and the current local time. Say "What time is it?" / "What's today's date?" vision-agents/agent.py get_current_time()
remember Memory tool Saves a short note to a local file so Alloy can recall it later. Say "Remember that my router is in the closet." vision-agents/agent.py remember() → notes.json
recall Memory tool Reads back the notes you've asked Alloy to remember. Say "What do you remember?" / "Where's my router?" vision-agents/agent.py recall() → notes.json
search_web Info tool (optional) Searches the web for current facts/news via Tavily. Degrades gracefully if no key is set. Say "Search the web for…". Requires TAVILY_API_KEY (optional at setup). vision-agents/agent.py search_web()
Honesty rule Safety / behavior Alloy admits when it has no tool for a request and never invents facts, numbers, or results. Always on (baked into the system prompt). vision-agents/agent.py INSTRUCTIONS
Complete Setup Scan · install · launch Scans your PC (Computer Setup Search), installs uv + Python 3.13 + libraries, collects keys, and launches — all in one file. ▶ complete-setup.bat (download & double-click) — see the banner above for how links work. vision-agents/complete-setup.bat · scan.ps1 · setup.bat
API keys / config Configuration Stream, Anthropic, Deepgram, ElevenLabs, Moondream (+ optional Tavily) keys, stored locally. Setup writes them to .env; edit that file to change keys later. vision-agents/.env (from .env.example)

ECHO — Telegram Markets Agent n8n

A Telegram bot (text / voice / image) on n8n with Gmail, Calendar, Contacts & web search. Import into n8n Cloud. Folder: echo/

NameFunctionSummary of featureActivate (how to activate)File location
Text chat Conversation Send text to the bot; ECHO replies with its markets persona, tools, and memory. Message the Telegram bot any text. echo/ECHO.json Switch → text
Voice chat Conversation Send a voice note; it's transcribed (Whisper), answered, and replied to as a voice note. Send a Telegram voice message. echo/ECHO.json Transcribe · Audio Response
Image chat Vision Send a photo (e.g. a chart); the vision model describes it and feeds that into the agent. Send a Telegram photo (optionally with a caption/question). echo/ECHO.json Analyze Image → Image Agent Input
Memory Context Remembers the last 20 turns per chat so the conversation stays coherent. Automatic, keyed on your Telegram chat id. echo/ECHO.json Window Buffer Memory
Tools Actions Google Search (SerpAPI), Get/Send Email (Gmail), Get/Set Calendar, Contacts (Pinecone). Ask in plain language; ECHO picks the tool. Connect each credential in n8n. echo/ECHO.json ai_tool nodes
Sender allowlist Security Closed by default — only your Telegram id can use the bot; everyone else is dropped. Set owner_chat_id in the Owner ID node. echo/ECHO.json Authorized? · Owner ID
Tap-to-approve email Security (human-in-loop) ECHO can't send email on its own — it proposes one and you approve via Telegram buttons. Ask ECHO to email someone, then tap Approve / Cancel. echo/ECHO.json Approve Send? → Send Email
Recipient allowlist Security Outbound email is blocked unless the recipient's domain is on an editable allowlist. Edit ALLOWED_DOMAINS in the Recipient Allowed? node. echo/ECHO.json Recipient Allowed?
Import & setup Onboarding Step-by-step guide to import the workflow into hosted n8n Cloud and connect credentials. Follow the README; import ECHO.json via n8n → Import from File. echo/README.md
